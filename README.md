# hotedit

**Edit any HTML file in your browser — text, styles, layout and charts — and save the
changes straight back into the file.** Built for the HTML reports that AI assistants write.

![hotedit tour: edit text, restyle, change Plotly, Chart.js, Vega-Lite and Mermaid charts, edit maths, add and drag blocks, leave a note for the AI agent](https://raw.githubusercontent.com/Thewhey-Brian/htmledit/main/demo/hotedit-demo.gif)

▶ [Watch the full 90-second tour (MP4)](https://github.com/Thewhey-Brian/htmledit/raw/main/demo/hotedit-tour.mp4) · or try it yourself: `npx hotedit demo`

AI assistants produce a lot of HTML: reports, dashboards, summaries. They look great, but
fixing a typo, renaming a chart title or moving a section means digging through thousands
of lines of generated markup, or asking the AI again. hotedit opens the page in your
browser so you can click what you see and change it. Only the bytes you changed are
rewritten, so the file stays clean, diff-friendly and yours.

## Quick start (30 seconds)

You need [Node.js 18+](https://nodejs.org). Then:

```bash
npx hotedit report.html
```

Your browser opens the page. Press **E** (or click **✎ Edit**), click any text and type.
Changes are saved into `report.html` as you go, and **⌘Z / Ctrl+Z** undoes them.

Just want to see it? Open a sample report (charts, maths, diagrams) in a throwaway copy:

```bash
npx hotedit demo
```

Not sure which file? Run it with no file and click one from the list:

```bash
npx hotedit          # lists the HTML files in this folder
```

To install it permanently, so you can just type `hotedit`:

```bash
npm install -g hotedit
hotedit report.html
```

## What you can do

| | How |
|---|---|
| **Edit text** | Click and type; the caret lands where you click. Enter saves, Esc cancels, ⌘B / ⌘I for bold and italic. In a list, Enter at the end of an item starts a new one. |
| **Add things** | Select a block and click **＋**: paragraph, heading, list or list item, box, quote, table, code, divider, image, chart, Mermaid diagram or your own HTML. Choose above, below or inside. |
| **Move things** | Drag **⠿** to move a block anywhere: list items into another list, a paragraph into a box. Or use **⋯ → Move up / down** (Alt+↑ / Alt+↓). |
| **Style** | **Aa**: size, weight, colour, alignment, font, spacing, background, corners and border. |
| **Charts** | Click a Plotly, Chart.js, Vega-Lite or Mermaid chart. **Chart** gives dropdowns, checkboxes and colour pickers for type, titles, axes, legend and series. **Data** is an editable table with + row. **Code** is the full spec. The chart updates live. |
| **Images & links** | **🖼** replaces an image, **🔗** changes a link. |
| **Everything else** | **⋯**: duplicate, hide, delete, or **Edit HTML** for the selected block. The name chip (e.g. *Paragraph ▴*) selects the block around it. |
| **Ask AI, live** | **✨** on a block (or **✨ AI** in the top bar for the whole page): type what should change, and Claude edits the page while you watch. Every change glows as it lands and **Undo AI changes** takes them all back. Or choose **Leave as note** for later. |

Things that are generated by the page's own scripts, such as KaTeX maths, Mermaid output or
tables built in JavaScript, are never saved as rendered output. hotedit opens their
*source* instead.

## Working with AI agents

### ✨ Built in: ask, and watch it change

Click **✨**, say what you want ("make this shorter", "turn the bars orange", "add a row
for March"), and press **Do it**. The AI reads the page, makes small edits in the file and
each one shows up in your browser straight away. Connect it once with **⚙**:

* **Claude login**: uses your Claude plan through [Claude Code](https://claude.com/code).
  Install it and run `claude` once to log in. Nothing else to set up.
* **Anthropic API key**: paste a key (kept only on your computer, in
  `~/.htmledit/config.json`), or set `ANTHROPIC_API_KEY`. Uses `claude-opus-5-5` unless you
  pick another model.

The AI can only read and edit this one page, and all its changes are normal undo steps.

### Your own agent, live (MCP)

Give any coding agent that speaks MCP (Claude Code, Codex, Cursor…) hotedit's tools, and
it can open a report in your browser and edit it while you watch:

```bash
claude mcp add hotedit -- npx -y hotedit mcp
codex mcp add hotedit -- npx -y hotedit mcp
```

Tools: `open` (opens the file in hotedit and your browser), `outline`, `read`, `edit`
(saved and shown live), `notes` and `resolve_note`. The agent finds pages you already have
open in hotedit, too.

### Notes for later

Leave a note (✨ → **Leave as note**) for anything you'd rather hand over in a batch
("recompute this table", "make this claim more cautious"). Agents read them with the
`notes` tool or the command line:

```bash
hotedit comments report.html                 # notes as markdown: request, quoted text, line, CSS path, snippet
hotedit comments report.html --json          # the same, machine-readable
hotedit comments report.html --wait          # wait for the next note
hotedit comments report.html --resolve 3fa2c1 --note "recomputed from the manifest"
```

**Claude Code skill.** Install it once, and Claude Code writes reports that are easy to
edit (text in HTML, chart specs inline), hands you the command to open them, and picks up
your notes:

```bash
npx hotedit skill install            # for all projects (~/.claude/skills)
npx hotedit skill install --project  # for this project only (./.claude/skills)
npx hotedit skill print              # print it, for AGENTS.md or another agent
```

## How it works

```
report.html ──parse (keeps source positions)──► served copy with element ids + editor overlay
     ▲                                                              │
     └──────── small byte patch ◄── map your edit back to source ◄──┘
```

* **Your file is never "re-written".** The editor and the element ids exist only in the
  copy the local server sends to your browser. Each edit becomes a minimal patch on the
  original bytes. Entities like `&middot;`, quote styles, indentation and comments
  elsewhere stay exactly as they were.
* **Charts are edited in their source.** The chart spec literal in the page's `<script>` is
  patched value by value, keeping its own quote and key style.
* **Safe by default.**
  * A backup is taken when a session starts (`~/.htmledit/backups/`).
  * Undo and redo cover every change.
  * If the file changes on disk (say, your agent edited it), the page reloads.
  * Files that aren't UTF-8 are refused rather than corrupted.
  * The server only listens on `127.0.0.1` and checks a per-session token.

## FAQ

**Does it work on any HTML file?** Yes, any local `.html` file: hand-written,
AI-generated, or exported from Jupyter, plotly.py, R Markdown or Quarto. It is tested on
pages with KaTeX, Mermaid, inline SVG charts, JavaScript-built dashboards, base64 images
and deliberately odd markup.

**Will it mess up my file?** It is designed not to. Every test page is opened, every
editable element is saved unchanged, and the file must stay byte-identical. Each real edit
must produce exactly the expected diff.

**Does it need the internet?** No, hotedit runs locally. Your page may load its own
libraries from a CDN, as many AI reports load KaTeX or Plotly.

**Which browsers?** Any modern browser. Automated tests run in Chromium.

**Where do notes live?** In `.htmledit/<file>.comments.json` next to your HTML. The HTML
itself is never touched by notes.

**Can I edit content that a script builds?** Use **⋯ → Edit HTML** on the script's block,
or ask the AI with ✨.

## Limitations

* One HTML file at a time. External `.css` and `.js` files are not edited, and styles are
  written as inline `style` attributes.
* Chart specs must be literals in an inline `<script>` (directly, or through
  `const spec = {...}`). Specs computed at runtime or loaded from separate files open as
  source.
* Undo history lasts for the session. Backups persist.

## Related tools

* [html-visual-editor](https://github.com/matongAI-lab/html-visual-editor) has a nice
  touch-up UI, but downloads a new file and has no chart editing.
* [Lavish](https://github.com/kunchenguid/lavish-axi) has a great agent feedback loop
  (it inspired 💬), but you can't edit the page yourself.
* GrapesJS, VvvebJs and Pinegrow are full page builders that re-serialise documents.
* `document.designMode` saves whatever the scripts rendered.
